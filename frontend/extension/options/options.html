Bảo vệ nền, chỉ hiện cảnh báo khi thật sự cần chú ý.

Kích hoạt tài khoản

Lấy key tại Web App → Tài khoản → API & MCP key. Key cần quyền đánh giá URL, nội dung và file.

Gateway

URL, email đang mở và tệp EXE cần kiểm tra được gửi tới Gateway này.

Quyền riêng tư

API key được lưu trong vùng riêng của extension. EXE chỉ được phân tích tĩnh và tra cứu hash; extension không yêu cầu Gateway chia sẻ mẫu với nhà cung cấp ngoài.
